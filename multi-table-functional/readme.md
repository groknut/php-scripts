

## Таблица умножения (функциональный способ)

Спроектируйте пользовательскую функцию на PHP для генерации таблицы умножения любой размерности.

На вход функция принимает 2 параметра:

- `$x` - конечное число по оси `X`
- `$y` - конечное число по оси `Y`

По умолчанию каждый из параметров имеет значение `10`. \
На выход функция отдает строкой сформированную таблицу умножения.

После вызова функции необходимо отобразить ее результат в браузер.
